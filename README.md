# B1 Layout Toolbox – releases

Downloads of **B1 Layout Toolbox** for SAP Business One (Crystal layouts, queries, form settings).

- Get the newest version from **[Releases](../../releases/latest)**:
  - `B1LayoutToolbox-<version>.exe` – full, nothing to install (.NET included)
  - `B1LayoutToolbox-<version>-lite.exe` – small, needs the .NET 8 Desktop Runtime (x64)
- Needs the SAP Business One DI API (64-bit) on the PC.
- From version 1.60.0 the toolbox checks this page at start and every 6 hours and offers **Update now**.

This repository holds only the release files; the source code is kept elsewhere.
